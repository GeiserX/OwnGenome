# Changelog

## Unreleased

- Step 27 (CPIC lookup) reads PharmCAT's report with `og pgx cpic-report`, in the Rust `og` binary, instead of `bin/pgx_parse.py`, which is gone. The Nextflow `CPIC_LOOKUP` module runs the same command. Run `scripts/setup.sh --og` before step 27. The phenotype table, the comparison table and the recommendations are the same, byte for byte, on every case we test, with these fixes: the tables are written under a temporary name and renamed into place, so a stopped step leaves no half-written file; a field of the report with an unexpected type reads as missing instead of stopping the step with a Python traceback; two or more guidance sources the parser does not know are listed by name, not in an order that changed from run to run; the `Date:` line is the date in UTC, and the hidden option `--date YYYY-MM-DD` sets it for tests. No output file, column or option changes.
- Genome map, first pieces, in the Rust `og` binary. `og map build` writes one person's map document: the chromosome bands, the runs of homozygosity, and every finding with a place on the genome (its own position, or its gene's span). A result the page keeps closed (a finding to act on, and APOE on every page) is tagged with its id on every row that could reveal it, so the page's own closed-result rule hides those rows too. `og map genes` builds the gene and exon files once per GENCODE release, offline. No pipeline output, option or page changes yet; the live page starts drawing the map in a later change. The format is in `rust/crates/og-map/README.md`.
