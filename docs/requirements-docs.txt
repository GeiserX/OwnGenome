# The docs site builder, Zensical, and every package it needs, each pinned
# with the sha256 of its wheels. .github/workflows/docs.yml installs them in
# PYTHON_IMAGE (versions.env), never on the runner's own Python, with
#   pip install --require-hashes --no-deps --only-binary :all: -r this file
# so pip installs exactly these wheels: nothing resolved, nothing built. The
# hashes cover the pure-Python wheels and the CPython 3.15 (or abi3)
# manylinux wheels for x86_64 and aarch64.
#
# To refresh (a new Zensical, or a new Python minor in PYTHON_IMAGE), from
# the repository root, with docker, curl and jq:
#   . ./versions.env
#   docker run --rm "$PYTHON_IMAGE" pip install -q --disable-pip-version-check \
#     --root-user-action=ignore --dry-run --only-binary :all: --report - \
#     zensical==<version> </dev/null \
#     | jq -r '.install[].metadata | "\(.name | ascii_downcase)==\(.version)"' | sort
# then, for each name==version it prints, write the line and one --hash per
# wheel sha256 from
#   curl -fsSL https://pypi.org/pypi/<name>/<version>/json | jq -r '.urls[]
#     | select(.packagetype == "bdist_wheel") | .filename as $f
#     | select(($f | endswith("-py3-none-any.whl"))
#       or (($f | test("-(cp315-cp315|cp3[0-9]+-abi3)-"))
#         and ($f | test("manylinux[^-]*_(x86_64|aarch64)\\.whl$"))))
#     | .digests.sha256' | sort
# (replace cp315 with the new Python's tag). Resolved on 2026-11-26.
